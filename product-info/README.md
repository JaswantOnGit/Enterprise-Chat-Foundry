# Product Info Source Documents

This folder is where the indexed source documents (`product_info_1.md` through `product_info_13.md` — the Contoso Trek retail product data used in this lab) should live.

These files were **not included in the upload**, so they aren't in this repo yet. To complete the package:

1. Download the sample data from the original K21Academy lab guide (Section 7, "Add Data and Test the Agent" → *Download the example Contoso Trek retail product data in a ZIP file*).
2. Drop the extracted `.md` files into this folder.
3. Update the main `README.md` file-count reference if the number of files differs.

Once added, this folder documents exactly what was fed into the `enterprise-index` vector store — which matters for audit purposes (see `governance/02_RAID_Log.md`, risk R1).
